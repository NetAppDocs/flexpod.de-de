= Schlussfolgerung
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Die Bereitstellung von FlexPod Edge mit softwaredefiniertem Speicher bietet Kunden einen praktischen Weg zu Enterprise-Datendiensten am Edge. Die Architektur kombiniert Ciscos kompakte, zentral verwaltete Unified Edge Plattform mit den ausgereiften Datendiensten von ONTAP und ermöglicht softwaredefinierten Speicher in einem einzigen Gehäuse, das lokale Workloads unterstützt, bei denen Daten erstellt und verarbeitet werden.
